# Shawn Labs

## Matcraft

The Matcraft browser app is published at `/JiuJitsuApp/`. Its source is maintained in [JiuJitsuApp](https://github.com/msingh13/JiuJitsuApp/tree/codex/matcraft-personal-edition). Build it with `npm run build:pages`, then replace the contents of this repository’s `JiuJitsuApp/` directory with that `dist-pages/` build. The static edition keeps visitor records and media in IndexedDB; it has no server-side account or sync.
