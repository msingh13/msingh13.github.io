# Shawn Labs

## Matcraft

The portfolio links to [Matcraft](https://msingh13.github.io/JiuJitsuApp/). Its source and automated GitHub Pages deployment are maintained in [JiuJitsuApp](https://github.com/msingh13/JiuJitsuApp/tree/codex/matcraft-personal-edition). Pushes to the app release branch run tests, build, and publish automatically. Do not manually copy app bundles into this repository.

The original `JiuJitsuApp/` bundle is retained here only as the pre-automation fallback; the project repository now owns that public Pages route. Browser data stays under the same origin and database name. Saving is automatic per browser profile; Settings provides complete local backup and restore, including media. No account or cloud sync is used.
